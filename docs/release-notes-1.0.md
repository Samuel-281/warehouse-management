# 仓库货物管理系统 1.0 发布说明

## 版本定位

1.0 是面向小团队试运行/正式使用的电脑端版本，重点覆盖仓库日常货物流转和查询。PDA 入口仍保留为草图，不作为本版本正式交付功能。

本版本的库存模型调整为“数量库存 + 条码追踪”双账本：

- 仓库库存以“仓库 + 货物 + 数量”为主。
- 条码只用于已经扫码进入系统的货物流转追踪。
- 厂家到货入库不再要求逐件扫码。

## 已包含能力

- 角色登录：超级管理员、仓库管理员、只读查询人员。
- 基础资料维护：货物、仓库、销售人员、终端店铺。
- 到货入库：厂家到货按商品数量入库，不创建条码追踪记录。
- 扫码出库：统一选择出库仓库、货物和去向，去向支持销售人员或其他仓库。
- 退回入库：销售退回和终端店铺退换货统一放在入库分支下。
- 销售退回：只选择回流仓库并扫码，系统自动识别条码当前所属销售人员。
- 终端店铺退换货：登记终端店铺、货物、数量、生产日期和条码。
- 库存查询：首页和查询页以仓库商品数量为主，条码详情用于查看已追踪条码的当前归属和流转记录。
- 单据查询：支持筛选、选择单据并导出。
- 操作日志和基础系统维护入口。
- 本地演示重置脚本已同步清理数量库存账，避免旧测试数据残留。

## 发布收口

- 登录页不再展示测试账号和默认密码。
- 新增账号不再预填固定默认密码。
- 网页端数据重置入口保留给超级管理员，执行前必须输入确认文字。
- 生产网页端重置只清理业务数据，不重新写入演示数据。
- 部署方向调整为阿里云 ECS 同机部署，不再使用 Netlify/Neon 方案。

## 暂不包含

- PDA 正式业务闭环。
- 盘点、库存预警、成本核算。
- 外部 ERP、财务、电商或物流系统集成。
- 企业级高可用和复杂审计报表。
