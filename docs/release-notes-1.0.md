# 仓库货物管理系统 1.0 发布说明

## 版本定位

1.0 是面向小团队试运行/正式使用的电脑端版本，重点覆盖仓库日常货物流转和查询。PDA 入口仍保留为草图，不作为本版本正式交付功能。

## 已包含能力

- 角色登录：超级管理员、仓库管理员、只读查询人员。
- 基础资料维护：货物、仓库、销售人员、终端店铺。
- 入库：厂家到货、终端店铺退换货。
- 出库：仓库之间挪仓、销售出库。
- 销售退回：销售人员名下未售完货物回流仓库。
- 库存查询：按仓库、销售人员、货物、条码查询，并查看条码详情和流转记录。
- 单据查询：支持筛选、选择单据并导出。
- 操作日志和基础系统维护入口。

## 发布收口

- 登录页不再展示测试账号和默认密码。
- 新增账号不再预填固定默认密码。
- 正式运行模式默认关闭网页端数据重置入口。
- 部署方向调整为阿里云 ECS 同机部署，不再使用 Netlify/Neon 方案。

## 暂不包含

- PDA 正式业务闭环。
- 盘点、库存预警、成本核算。
- 外部 ERP、财务、电商或物流系统集成。
- 企业级高可用和复杂审计报表。
