# Web v1.2.0 发布说明

发布日期：2026-07-15

## 主要更新

1. 新增勤策签收关联，按唯一箱码同步收货单位和扫码时间。
2. 条码销售流转状态统一为“待签收”“已签收”“签收异常”。
3. 勤策签收成功后，条码当前归属更新为终端店铺，原出库销售人员继续保留在流转履历中。
4. 入库页面合并为“厂家到货”和“退回入库”两个入口。
5. 退回入库可同时处理待签收、已签收和未建档外部退货，不再填写终端店铺或生产日期。
6. 支持店铺退货未回仓、随后直接签收至另一店铺的业务流转；此过程不改变仓库数量库存。
7. 旧签收记录和重复同步不会覆盖更新的回仓或后续签收结果。

## 数据兼容

- 保留现有 Web 和 PDA 主要业务接口。
- 数据库迁移会为历史销售出库条码补充待签收或已签收状态，不清空业务数据。
- 原终端店铺接口暂时保留兼容，但不再作为当前界面的维护入口。

## 上线验证

- 厂家到货入库、统一退回入库和扫码出库。
- 待签收、已签收和签收异常查询。
- 勤策连接器重复同步去重。
- 条码详情中的销售人员出库和终端店铺签收履历。
- `/api/health` 返回 Web `1.2.0`、API `1`、数据库状态正常。
