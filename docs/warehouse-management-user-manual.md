## 2. 软件概述

本软件用于管理总仓、分仓、销售人员名下货物以及单件货物条码的流转情况。

系统以“每件货物一个唯一条形码编号”为核心追踪方式。每次厂家到货入库、终端店铺退换货入库、挪仓、销售出库、销售退回都会形成库存流水，方便后续查询某一件货物当前在哪里、曾经经过哪些环节、由谁操作。

第一阶段主要支持以下业务：

1. 厂家到货入库。
2. 终端店铺退换货入库。
3. 挪仓，从总仓转移到分仓。
4. 销售出库，将货物分配到销售人员名下。
5. 销售退回，将销售人员名下未销售完的货物条码重新回流到仓库。
6. 库存查询和库存流转查询。
7. PDA 扫码操作。

## 3. 重要概念

| 名称 | 说明 |
| --- | --- |
| 总仓 | 仓库体系的上级仓库。挪仓时只能从总仓转移到分仓。 |
| 分仓 | 隶属于总仓的下级仓库。 |
| 单件条形码编号 | 每件货物唯一不可重复的条码编号，是系统追踪货物的核心标识。 |
| 厂家到货入库 | 厂家发来的货物进入总仓或分仓。该入库来源不强制登记生产日期。 |
| 终端店铺退换货入库 | 终端店铺退回或换回的货物进入仓库。该业务必须登记生产日期。 |
| 挪仓 | 货物从总仓转移到分仓。挪仓无需分仓确认，提交后直接进入目标分仓库存。 |
| 销售出库 | 将仓库中的货物分配到销售人员名下，不分配到具体终端店铺。 |
| 销售退回 | 将销售人员名下未销售完的商品条码重新回流到仓库。该业务不登记终端店铺、生产日期和保质期。 |
| 保健酒 | 货物大类之一。终端店铺退换货入库时，默认保质期为生产日期三年后。 |
| 白酒 | 货物大类之一。终端店铺退换货入库时，默认无保质期。 |

## 4. 角色与权限

### 4.1 系统管理员

系统管理员主要负责系统基础配置和账号权限管理。

常用操作：

1. 创建和停用用户账号。
2. 分配用户角色。
3. 维护总仓、分仓、货物、销售人员等基础资料。
4. 查看系统操作日志。

### 4.2 仓库主管

仓库主管主要负责仓库业务管理和异常处理。

常用操作：

1. 查看各仓库库存。
2. 查看库存流转记录。
3. 查询销售人员名下货物。
4. 处理条码、库存归属等异常。

### 4.3 仓库操作员

仓库操作员主要负责日常入库、出库、扫码和库存查询。

常用操作：

1. 厂家到货入库。
2. 终端店铺退换货入库。
3. 挪仓。
4. 销售出库。
5. 销售退回。
6. 使用 PDA 扫码。

### 4.4 销售人员

销售人员主要查看分配到自己名下的货物。

常用操作：

1. 查询自己名下的货物清单。
2. 配合仓库进行销售退回。

## 5. 登录与首页

### 5.1 登录系统

操作步骤：

1. 打开系统登录地址。
2. 输入账号和密码。
3. 点击登录。
4. 登录成功后进入首页。

注意事项：

1. 用户账号由系统管理员创建。
2. 首次登录后建议修改默认密码。
3. 多次登录失败时，请联系系统管理员处理。

### 5.2 首页查看

首页主要用于快速了解系统状态和进入常用功能。

建议展示内容：

1. 当前总仓库存概览。
2. 当前分仓库存概览。
3. 销售人员名下货物概览。
4. 今日入库数量。
5. 今日出库数量。
6. 最近库存流转记录。
7. 常用入口：入库、出库、销售退回、库存查询。

## 6. 基础资料维护

基础资料是所有业务操作的前提。开始正式使用前，应先维护货物、仓库、销售人员等资料。

### 6.1 货物资料

货物资料用于定义系统中的货物品类。

必填信息：

| 字段 | 说明 |
| --- | --- |
| 货物编码 | 货物品类的唯一编码。 |
| 货物名称 | 货物名称。 |
| 货物大类 | 保健酒或白酒。 |
| 单位 | 件、箱、瓶等。 |
| 状态 | 启用或停用。 |

选填信息：

| 字段 | 说明 |
| --- | --- |
| 分类 | 货物所属分类。 |
| 规格型号 | 规格、型号、容量等。 |
| 品类条码 | 用于标识货物品类，不等同于单件唯一条码。 |
| 安全库存 | 后续库存预警可使用。 |
| 库存上限 | 后续库存预警可使用。 |

货物大类规则：

1. 货物大类为保健酒时，终端店铺退换货入库需要根据生产日期自动生成默认保质期截止日期。
2. 货物大类为白酒时，终端店铺退换货入库默认无保质期。

### 6.2 仓库资料

仓库只分为两级：总仓和分仓。

必填信息：

| 字段 | 说明 |
| --- | --- |
| 仓库编码 | 仓库唯一编码。 |
| 仓库名称 | 仓库名称。 |
| 仓库类型 | 总仓或分仓。 |
| 状态 | 启用或停用。 |

规则：

1. 分仓必须归属于一个总仓。
2. 停用仓库不能用于新增入库、出库、挪仓和销售退回。
3. 挪仓只能从总仓转移到分仓。

### 6.3 库区和库位

库区和库位用于精细记录货物在仓库中的位置。

常用字段：

| 字段 | 说明 |
| --- | --- |
| 仓库 | 库位所属仓库。 |
| 库区 | 可选，例如 A 区、B 区。 |
| 库位编码 | 同一仓库内唯一。 |
| 库位名称 | 展示名称。 |
| 状态 | 启用、停用或冻结。 |

### 6.4 销售人员

销售人员资料用于销售出库和销售退回。

常用字段：

| 字段 | 说明 |
| --- | --- |
| 销售人员编码 | 销售人员唯一编码。 |
| 姓名 | 销售人员姓名。 |
| 手机号 | 联系电话。 |
| 所属区域 | 负责区域。 |
| 状态 | 启用或停用。 |

规则：

1. 销售出库时必须选择启用状态的销售人员。
2. 停用销售人员不能作为新的销售出库对象。
3. 销售退回时，系统可根据条码自动识别当前所属销售人员。

### 6.5 终端店铺记录

终端店铺只用于记录终端店铺退换货来源，不用于销售出库分配。

常用字段：

| 字段 | 说明 |
| --- | --- |
| 店铺名称 | 终端店铺名称。 |
| 联系人 | 店铺联系人。 |
| 联系电话 | 店铺联系电话。 |
| 地址 | 店铺地址。 |

注意事项：

1. 终端店铺退换货和销售退回是两个不同业务。
2. 销售出库不需要选择终端店铺。
3. 销售退回不需要选择终端店铺。

## 7. 厂家到货入库

厂家到货入库用于将厂家发来的货物登记到总仓或分仓库存。

### 7.1 适用场景

适用于厂家发货到仓库的场景。

厂家到货入库不强制登记生产日期，也不自动计算保质期。

### 7.2 操作入口

电脑端路径建议：

`入库` -> `厂家到货入库`

PDA 路径建议：

`PDA 首页` -> `入库` -> `厂家到货`

### 7.3 操作步骤

1. 进入厂家到货入库页面。
2. 新建入库单。
3. 入库来源选择厂家到货。
4. 选择入库仓库，可选择总仓或分仓。
5. 选择货物。
6. 录入到货数量。
7. 扫描或录入每件货物的单件条形码编号。
8. 确认条码数量与到货数量一致。
9. 点击提交。
10. 系统完成入库，并生成库存流水。

### 7.4 系统校验

提交时系统应校验以下内容：

1. 货物是否存在且启用。
2. 入库仓库是否存在且启用。
3. 单件条形码编号是否为空。
4. 单件条形码编号是否已经存在。
5. 本次录入条码是否重复。
6. 条码数量是否与入库数量一致。

### 7.5 入库结果

厂家到货入库提交后：

1. 每个条码生成一条单件库存记录。
2. 当前归属类型变为总仓库存或分仓库存。
3. 当前仓库为本次选择的入库仓库。
4. 入库来源记录为厂家到货。
5. 系统生成库存流水。

## 8. 终端店铺退换货入库

终端店铺退换货入库用于处理终端店铺退回或换回的货物。

该业务是入库业务，与销售退回不同。

### 8.1 适用场景

适用于终端店铺将货物退回仓库或换货回仓库的场景。

该业务必须登记生产日期，并根据货物大类处理保质期。

### 8.2 操作入口

电脑端路径建议：

`入库` -> `终端店铺退换货入库`

PDA 路径建议：

`PDA 首页` -> `入库` -> `终端店铺退换货`

### 8.3 操作步骤

1. 进入终端店铺退换货入库页面。
2. 新建入库单。
3. 入库来源选择终端店铺退换货。
4. 选择退换货进入的仓库，可选择总仓或分仓。
5. 记录退换货来源店铺，是否必填以后续业务确认为准。
6. 选择货物。
7. 扫描或录入退回货物的单件条形码编号。
8. 登记每件货物的生产日期。
9. 系统根据货物大类生成默认保质期截止日期。
10. 点击提交。
11. 系统完成入库，并生成库存流水。

### 8.4 保质期规则

| 货物大类 | 生产日期 | 默认保质期截止日期 |
| --- | --- | --- |
| 保健酒 | 必填 | 生产日期三年后 |
| 白酒 | 必填 | 无保质期，保质期截止日期为空 |

### 8.5 系统校验

提交时系统应校验以下内容：

1. 入库来源是否为终端店铺退换货。
2. 货物是否存在且启用。
3. 货物大类是否为保健酒或白酒。
4. 入库仓库是否存在且启用。
5. 单件条形码编号是否唯一。
6. 生产日期是否已填写。
7. 保健酒是否已生成默认保质期截止日期。

### 8.6 入库结果

终端店铺退换货入库提交后：

1. 货物进入所选仓库库存。
2. 入库来源记录为终端店铺退换货。
3. 单件库存记录保存生产日期。
4. 保健酒保存保质期截止日期。
5. 白酒保质期截止日期为空。
6. 系统生成退换货入库流水。

## 9. 挪仓出库

挪仓用于将货物从总仓转移到分仓。

### 9.1 适用场景

适用于总仓向分仓调配货物。

挪仓无需分仓确认，总仓提交后货物直接进入目标分仓库存。

### 9.2 操作入口

电脑端路径建议：

`出库` -> `挪仓出库`

PDA 路径建议：

`PDA 首页` -> `出库` -> `挪仓`

### 9.3 操作步骤

1. 进入挪仓出库页面。
2. 新建挪仓单。
3. 源仓库选择总仓。
4. 选择目标分仓。
5. 扫描或录入需要挪仓的单件条形码编号。
6. 系统校验条码是否在总仓库存中。
7. 确认条码清单。
8. 点击提交。
9. 系统将条码从总仓库存转入目标分仓库存。

### 9.4 系统校验

提交时系统应校验以下内容：

1. 源仓库是否为总仓。
2. 目标仓库是否为分仓。
3. 条码是否存在。
4. 条码当前是否在总仓库存中。
5. 条码是否处于可出库状态。
6. 条码是否被冻结或作废。

### 9.5 挪仓结果

挪仓提交后：

1. 条码当前归属从总仓库存变为分仓库存。
2. 当前仓库变为目标分仓。
3. 系统生成挪仓流水。
4. 分仓无需另行确认收货。

## 10. 销售出库

销售出库用于将仓库中的货物分配到销售人员名下。

销售出库不分配到具体终端店铺。

### 10.1 适用场景

适用于将总仓或分仓中的货物交给销售人员。

总仓和分仓都可以进行销售出库。

### 10.2 操作入口

电脑端路径建议：

`出库` -> `销售出库`

PDA 路径建议：

`PDA 首页` -> `出库` -> `销售出库`

### 10.3 操作步骤

1. 进入销售出库页面。
2. 新建销售出库单。
3. 选择出库仓库，可选择总仓或分仓。
4. 选择销售人员。
5. 扫描或录入需要分配的单件条形码编号。
6. 系统校验条码是否在所选仓库库存中。
7. 确认条码清单。
8. 点击提交。
9. 系统将货物从仓库库存转为销售人员名下货物。

### 10.4 系统校验

提交时系统应校验以下内容：

1. 出库仓库是否启用。
2. 销售人员是否启用。
3. 条码是否存在。
4. 条码是否在所选仓库库存中。
5. 条码是否处于可出库状态。
6. 条码是否被冻结或作废。

### 10.5 出库结果

销售出库提交后：

1. 条码当前归属类型变为销售人员名下。
2. 所属销售人员变为本次选择的销售人员。
3. 当前仓库可保留最近出库仓库。
4. 系统生成销售出库流水。

## 11. 销售退回

销售退回用于将销售人员名下未销售完的商品条码重新回流到仓库。

销售退回和终端店铺退换货是两个不同业务。

### 11.1 适用场景

适用于销售人员将未销售完的货物交回仓库。

该业务只处理条码回流，不登记终端店铺、生产日期和保质期。

### 11.2 操作入口

电脑端路径建议：

`出库` -> `销售退回`

PDA 路径建议：

`PDA 首页` -> `销售退回`

### 11.3 操作步骤

1. 进入销售退回页面。
2. 新建销售退回单。
3. 选择条码回流仓库，可选择总仓或分仓。
4. 扫描或录入未销售完货物的单件条形码编号。
5. 系统根据条码自动识别当前所属销售人员。
6. 确认条码清单。
7. 点击提交。
8. 系统将条码从销售人员名下重新回流到所选仓库库存。

### 11.4 系统校验

提交时系统应校验以下内容：

1. 条码是否存在。
2. 条码当前是否归属于销售人员名下。
3. 条码是否被冻结或作废。
4. 回流仓库是否存在且启用。

### 11.5 退回结果

销售退回提交后：

1. 条码当前归属类型变为总仓库存或分仓库存。
2. 当前仓库变为回流仓库。
3. 原所属销售人员从当前归属中移除，但库存流水保留历史记录。
4. 系统生成销售退回流水。

销售退回不会执行以下操作：

1. 不记录终端店铺。
2. 不登记生产日期。
3. 不重新计算保质期。
4. 不改变该条码原有生产日期和保质期信息。

## 12. 库存查询

库存查询用于查看当前库存、销售人员名下货物、单件条码详情和库存流转。

### 12.1 操作入口

电脑端路径建议：

`库存` -> `实时库存查询`

PDA 路径建议：

`PDA 首页` -> `库存查询`

### 12.2 查询条件

常用查询条件：

| 条件 | 说明 |
| --- | --- |
| 仓库类型 | 总仓或分仓。 |
| 仓库名称 | 查询指定仓库库存。 |
| 销售人员 | 查询指定销售人员名下货物。 |
| 货物编码 | 按货物编码查询。 |
| 货物名称 | 按货物名称查询。 |
| 单件条形码编号 | 精确查询某一件货物。 |
| 当前归属类型 | 总仓库存、分仓库存、销售人员名下等。 |
| 当前状态 | 在库、已挪仓、已分配销售、已销售退回等。 |

## 13. PDA 使用说明

PDA 主要用于仓库现场扫码，提高入库、出库、销售退回和库存查询效率。

### 13.1 PDA 登录

操作步骤：

1. 打开 PDA 浏览器或系统入口。
2. 输入账号和密码。
3. 点击登录。
4. 进入 PDA 首页。

### 13.2 PDA 厂家到货入库

操作步骤：

1. 进入 PDA 入库。
2. 选择厂家到货。
3. 选择入库仓库。
4. 选择货物。
5. 扫描每件货物的单件条形码编号。
6. 确认条码数量。
7. 提交入库。

### 13.3 PDA 终端店铺退换货入库

操作步骤：

1. 进入 PDA 入库。
2. 选择终端店铺退换货。
3. 选择入库仓库。
4. 选择货物。
5. 扫描单件条形码编号。
6. 录入生产日期。
7. 系统自动处理保质期。
8. 提交入库。

### 13.4 PDA 挪仓

操作步骤：

1. 进入 PDA 出库。
2. 选择挪仓。
3. 选择目标分仓。
4. 扫描需要挪仓的单件条形码编号。
5. 确认条码清单。
6. 提交。

### 13.5 PDA 销售出库

操作步骤：

1. 进入 PDA 出库。
2. 选择销售出库。
3. 选择出库仓库。
4. 选择销售人员。
5. 扫描需要分配的单件条形码编号。
6. 确认条码清单。
7. 提交。

### 13.6 PDA 销售退回

操作步骤：

1. 进入 PDA 销售退回。
2. 选择条码回流仓库。
3. 扫描销售人员退回的单件条形码编号。
4. 系统自动识别当前所属销售人员。
5. 确认条码清单。
6. 提交。

注意事项：

1. 销售退回只做条码回流仓库。
2. 销售退回不录入终端店铺。
3. 销售退回不录入生产日期。
4. 销售退回不重新计算保质期。

### 13.7 PDA 库存查询

操作步骤：

1. 进入 PDA 库存查询。
2. 扫描单件条形码编号。
3. 查看货物名称、当前归属、当前仓库、所属销售人员、生产日期和保质期。
4. 如需查看历史，进入库存流转记录。

## 14. 单据管理

### 14.1 单据类型

系统第一阶段涉及以下单据：

1. 厂家到货入库单。
2. 终端店铺退换货入库单。
3. 挪仓单。
4. 销售出库单。
5. 销售退回单。
6. 库存调整单。

### 14.2 单据状态

常见状态：

| 状态 | 说明 |
| --- | --- |
| 草稿 | 已创建但尚未提交，不影响库存。 |
| 已完成 | 已提交并影响库存或货物归属。 |
| 已作废 | 单据不可继续使用。 |

### 14.3 单据规则

1. 第一阶段无需审核，单据提交后直接生效。
2. 已完成单据不可随意修改。
3. 需要纠正历史操作时，应通过作废、调整或补充单据处理。
4. 所有影响库存的单据都必须生成库存流水。

## 15. 常见异常处理

### 15.1 条码已存在

可能原因：

1. 该条码已经入库。
2. 本次入库重复扫描同一个条码。
3. 条码录入错误。

处理方式：

1. 使用库存查询按条码检索。
2. 确认条码当前状态。
3. 如确认为录入错误，删除本次错误明细后重新扫描。

### 15.2 条码不在当前仓库

可能原因：

1. 条码已经挪仓到其他仓库。
2. 条码已经销售出库到销售人员名下。
3. 选择的出库仓库错误。

处理方式：

1. 按条码查询当前归属。
2. 确认当前仓库或销售人员。
3. 重新选择正确业务或正确仓库。

### 15.3 销售退回时条码不属于销售人员

可能原因：

1. 条码仍在仓库库存中。
2. 条码已归属于其他销售人员。
3. 条码已作废或冻结。

处理方式：

1. 按条码查询当前归属。
2. 确认是否需要销售退回。
3. 如归属异常，联系仓库主管处理。

### 15.4 终端店铺退换货未填写生产日期

可能原因：

1. 操作员漏填生产日期。
2. PDA 页面未录入日期。

处理方式：

1. 补充生产日期。
2. 确认货物大类。
3. 重新提交入库。

### 15.5 保质期显示为空

可能原因：

1. 货物大类为白酒，默认无保质期。
2. 货物不是终端店铺退换货入库。
3. 生产日期未录入成功。

处理方式：

1. 查看货物大类。
2. 查看入库来源。
3. 如为保健酒终端退换货，检查生产日期是否已填写。

## 16. 业务边界说明

### 16.1 终端店铺退换货与销售退回的区别

| 对比项 | 终端店铺退换货入库 | 销售退回 |
| --- | --- | --- |
| 业务性质 | 入库来源之一 | 销售人员名下条码回流仓库 |
| 是否涉及终端店铺 | 是，可记录退换货来源店铺 | 否 |
| 是否登记生产日期 | 是，必须登记 | 否 |
| 是否计算保质期 | 是，根据货物大类处理 | 否 |
| 是否改变条码归属 | 是，进入仓库库存 | 是，从销售人员名下回到仓库 |
| 是否保存/计算保质期 | 是，按登记的生产日期和货物大类处理 | 否 |

### 16.2 销售出库与终端店铺无关

销售出库只需要将货物分配到销售人员名下，不需要分配到具体终端店铺。

### 16.3 条码生成不由系统负责

系统不关注条码如何生成，只负责：

1. 录入条码。
2. 校验条码不可重复。
3. 根据条码追踪库存和流转。

## 17. 日常操作建议

### 17.1 每日开始前

建议检查：

1. PDA 是否可正常登录。
2. 扫码功能是否正常。
3. 当日需要使用的货物资料是否已启用。
4. 当日需要使用的仓库和销售人员是否已启用。

### 17.2 每日结束前

建议检查：

1. 今日厂家到货入库是否全部提交。
2. 今日终端店铺退换货入库是否已登记生产日期。
3. 今日挪仓是否全部完成。
4. 今日销售出库是否全部提交。
5. 今日销售退回条码是否已回流到正确仓库。
6. 是否存在异常条码未处理。
